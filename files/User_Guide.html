0. 工具简介

本工具是一个单文件、纯前端、离线可用的数据脱敏与还原工具。无需联网、无需上传服务器，所有计算都在你本机浏览器内完成。适用于在向第三方、合作方、公开渠道分享数据前，对个人隐私与商业敏感信息进行脱敏处理，并在授权范围内还原。

覆盖格式：Excel / CSVWordPowerPointPDF图片ZIP（含嵌套）。其中结构化文本格式（表格、Word、PPT、ZIP 内文档）支持脱敏 + 还原；PDF / 图片支持两种模式：「遮挡式（不可逆）」保留原格式打码，或「转为 Word 脱敏（可逆）」提取文本令牌化后生成可还原的 Word。

⚠ 主字典（含全部明文映射）是最高敏感资产，务必本地独掌，严禁随脱敏文件外发。

1. 界面布局

工具采用左右分栏布局：

  • 左侧菜单：① 表格脱敏、② 文档脱敏、③ 还原（统一）、④ 全局字典，以及文档入口「使用帮助」「技术文档」。
  • 右侧工作区：随选中的菜单切换显示对应功能面板。

点击左侧任意菜单即可切换；当前所在功能以蓝色高亮标识。

2. 快速开始（第一次使用）

1
用 Chrome / Edge 浏览器打开 通用脱敏工具v2.html（双击文件即可）。
2
左侧选择「① 表格脱敏」或「② 文档脱敏」，上传你的文件。
3
选择每列 / 每类敏感信息的脱敏方法，点击生成。
4
下载脱敏后文件；如需还原，到「③ 还原」上传脱敏文件 + 主字典。
✓ 全部过程文件均只保存在你本机，不会上传任何服务器。

3. ① 表格脱敏（Excel / CSV）

操作步骤

1
点击「上传 Excel / CSV」，选择文件。工具自动读取首个工作表，第一行为表头，空行自动忽略。
2
在「配置每列脱敏方法」表格中，为每一列选择方法（见下方方法说明）。可设置掩码保留首尾位数与加密口令。
3
点击「生成脱敏四件套」，工具自动生成并下载：脱敏后文件、编码字典.json、脱敏方案.md、还原方案.md，同时把映射累计进全局字典。
4
在「预览」区查看前 15 行脱敏效果，可单独下载四类产物。

4. ② 文档脱敏（Word / PPT / 表格 / PDF / 图片 / ZIP）

Word / PPT / Excel / CSV

  • 上传后工具自动解析文本并跑 13 类敏感识别，列出每类命中样例。
  • 对每类勾选「是否脱敏」并选择方法（默认：可还原类→令牌化，手机/地址→掩码）。
  • 点击「生成脱敏文档」，输出新文件，命中值替换进全局字典。

ZIP（含嵌套）

  • 上传 ZIP 后自动递归处理内部所有支持的文件（包括 ZIP 内的 ZIP）。
  • Word/PPT/表格按内容脱敏后重打包；PDF/图片按遮挡式处理。

PDF / 图片（两种模式）

  • 转为 Word 脱敏（可逆 · 推荐）：PDF 用 pdf.js 抽取文本（含表单字段），图片用 tesseract.js OCR，自动令牌化全部敏感项后生成 .docx。因是结构化文档脱敏，可凭主字典还原。
  • 遮挡式（不可逆）：PDF 用 pdf.js 对敏感文本画黑色矩形，图片用 OCR 定位后打码，保留原格式但像素/版面信息丢失，无法还原。
  • 两类引擎（pdf.js、tesseract.js 及中文/英文训练数据）已本地化于 libs/ 目录，可彻底离线。

批量处理（文件夹 / 多文件）

  • 在「② 文档脱敏」页底部，把整个文件夹或多个文件拖入拖拽区（支持嵌套），或点击「选择文件夹 / 选择多个文件」。
  • 系统按默认策略自动脱敏（结构化文本令牌化/掩码，PDF/图片转为 Word 令牌化），结果打包为 批量脱敏结果.zip，并累计进全局字典；处理过程有进度条与逐文件日志。
⚠ 人员姓名识别较宽松（仅识别带称谓/姓名标记者），默认「保留」，请人工确认是否脱敏。

5. ③ 还原（统一）

1
上传脱敏文件（docx/pptx/xlsx/csv）。
2
上传对应的主字典 .json（即「④ 全局字典」下载的，或脱敏四件套里的编码字典）。
3
若含加密列/令牌，填写加密口令。
4
点击「还原为明文」，预览并下载《含明文》版本。
✓ 令牌化 / 加密 / 洗牌 / 可逆取整均可还原；掩码 / 哈希 / 泛化 / 删除 / 遮挡式不可还原。

5.1 实战案例：多表脱敏 Word 的还原

场景：你有三张原始表 → 分别脱敏生成三张 Excel + 三份编码字典 → 用外部工具合并生成一版 Word 文档（含脱敏数据）→ 需要还原回明文。

你需要准备

文件从哪来作用
脱敏 Word（.docx）外部工具从三张脱敏表生成包含令牌的待还原文档
主字典 .json三张表各自的编码字典.json 合并后下载令牌 → 明文的映射表
口令（可选）脱敏时用了「加密 AES」或「数值取整·可逆」才需要解密用

第一步：合并字典

1
进「④ 全局字典」，逐个「导入 主字典.json（合并）」三张表的 编码字典.json。
2
导入完成后点「下载 主字典.json」。若用了加密列，填口令后下载「下载 加密主字典.json」。

第二步：还原 Word

1
进「③ 还原（统一）」，上传脱敏 Word + 主字典 .json。
2
若含加密列/令牌，填写加密口令。
3
点「还原为明文」→ 下载「下载 还原版」得到 _含明文.docx。
✓ 还原是文本替换：工具解析 Word 的 Open XML，把每个令牌（如 K1-0001）在字典中查回明文填入。掩码/哈希/泛化等不可逆方法不进入字典，Word 中保持原样。
⚠ 外部工具若对文本做了二次处理（加前缀、截断、换行拼接），令牌可能被破坏导致还原失败或部分失败。还原后请预览核对。

6. ④ 全局字典（跨文件同值同码）

  • 同值同码：同一明文字符串，无论在哪个文件、哪列、哪类，都映射为同一个令牌，便于跨表关联与一致还原。
  • 下载主字典：导出含全部明文映射的 主字典.json，是还原的唯一依据。
  • 加密导出：可设置口令，将主字典以 AES-GCM 加密后导出（主字典_加密.json），导入时凭同一口令解密合并；丢失口令将无法还原。
  • 导入（合并）：可把多个字典（含加密字典）合并到当前会话，支持跨批次还原。
  • 清空：清空当前会话字典（仅内存，不影响已下载文件）。
⚠ 主字典等同于「明文全集」，丢失则不可逆数据永久无法还原；泄露则脱敏形同虚设。请加密保管、切勿外发。

9. 安全与合规

  • 数据不出本机：全部运算在浏览器本地完成，无网络上传。
  • 口令不落盘：加密口令仅用于本次会话派生密钥，不写入字典文件。
  • 合规参考：设计参照 GB/T 37988-2019（PA10）、GB/T 35273、JR/T 0171-2020 等。
  • 主字典保管：本地加密存储、最小化分发、用完即清。

10. 常见问题（FAQ）

Q1：脱敏后还能还原吗？

取决于所用方法。令牌化/加密/洗牌/可逆取整可还原（需主字典，加密类还需口令）；掩码/哈希/泛化/删除/遮挡式不可还原。需要还原的字段务必使用可逆方法。

Q2：多个文件能用同一字典还原吗？

可以。全局字典「同值同码」，跨文件共享。在「④ 全局字典」下载主字典，或把多个字典「导入合并」。

Q3：Word 里的值被拆成几段格式，会漏替换吗？

工具按段落（run）聚合文本后做替换，常规文档可靠。极个别复杂嵌套排版存在漏替风险，生成后请预览核对。

Q4：PDF / 图片能还原吗？

选「遮挡式」时像素/版面被打码，不可逆；选「转为 Word 脱敏」时，工具先把内容提取为文本并令牌化生成 .docx，可凭主字典还原。需要还原请使用「转为 Word」模式。

Q5：引擎与离线

表格、Word、PPT、ZIP 完全离线。PDF/图片引擎（pdf.js、tesseract.js 及训练数据）已随工具本地化在 libs/ 目录，打开工具所在文件夹即可彻底离线运行；若本地引擎缺失则自动回退 CDN（需联网一次）。
