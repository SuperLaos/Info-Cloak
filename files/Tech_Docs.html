1. 总体架构

纯前端单页应用（SPA），无后端、无网络上报。核心分三层：

  • 识别层：对文本跑 13 类正则，产出 {type:{values,cls}}。
  • 处理层：按所选方法把明文映射为脱敏值，并把映射写入全局字典 G。
  • 输出/还原层：生成脱敏产物（含字典）；还原时以字典为唯一依据反查。

入口为四个功能面板 + 两个文档面板（使用帮助 / 技术文档，通过 iframe 嵌入）。

3. 核心数据模型：全局字典 G

const G = {
  byCat:{},        // 类别+明文 -> 令牌（去重）
  tok:{},          // 令牌 -> {original, method, type, category}
  counters:{},     // 每类计数
  catIndex:{},     // 类别 -> 序号前缀 K{n}
  catCount:0,
  salt:null,       // 加密盐（base64），首次需要时生成
  columns:{}       // 表格列方法元数据（供还原路由）
};

同值同码：getToken(category,value,method,type) 以 category\u0000value 为键，已存在则复用令牌。跨文件、跨列、跨类同一明文共享令牌，保证关联一致与一致还原。

4. 脱敏算法

4.1 令牌化（可逆）

token = 'K'+catIndex + '-' + pad4(计数器++)   // 例 K1-0001
G.tok[token] = {original, method:'token', ...}

4.2 加密 AES-GCM（可逆，需口令）

key  = PBKDF2(password, salt, 100000, SHA-256) -> AES-256-GCM
ct   = AES-GCM.encrypt(value, iv=random12B)
store = b64(iv)+':'+b64(ct)     // 密文本身可作脱敏值

还原：decryptVal(salt,password,store)。salt 存于字典（加密列元数据），口令不落盘。

4.3 掩码 / 哈希 / 泛化（不可逆）

  • 掩码：前keep位 + '*'*(len-2keep) + 后keep位。
  • 哈希：SHA-256(salt固定串 + value) 取前 16 位 base64。
  • 泛化：数字按量级归并区间（<10 / 10-100 / …），日期归并到年。

4.4 随机洗牌（可逆，按值映射）

列内为每个不同值分配随机占位符 S{col}-{randHex}，存入 G.tok 与列 map。还原时按值反查。注意：是按值映射而非按行号重排，因此行顺序变化仍能还原。

4.5 数值取整（可逆 / 不可逆）

roundTo(n,p): p>=0 -> trunc(n/10^p)*10^p;  p<0 -> round(n*10^-p)/10^-p
不可逆：丢弃余数
可逆：  余数 rem = n - masked, 加密后作为隐藏列 {列名}_余项 随行写入

还原：原值 = 取整值 + decrypt(余项)。

5. 13 类敏感识别（启发式）

每类一条正则，扫描文本收集去重后的命中集。典型规则：

person : (?<=(姓名|联系人|经办人|...)\s*[:：]?)[一-龥]{2,3} | [一-龥]{2,3}(?=先生|女士|...)
phone  : 1[3-9]\d{9}
idcard : [1-9]\d{5}(?:18|19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx]
address: (?<=([\s，。、：:；;（）()【】]|地址|位于|户籍|...))[一-龥]{1,}(省|市|区|路|...)

已知局限

  • 姓名识别保守（仅带称谓/标记者），误报率与漏报率并存，默认「保留」。
  • 同一串可能命中多类（如身份证同时像证件号与信用代码），按全局字典去重只生成一个令牌。
  • 正则难覆盖所有变体；建议生成前人工核对样例。

6. 表格脱敏流程

XLSX.read(arrayBuffer) -> sheet_to_json(header:1)
-> 首行作表头，空行过滤
-> 逐列逐行按 COLCFG 方法转换
-> 可逆取整追加隐藏列 {列}_余项
-> 列元数据写入 G.columns（token/encrypt/shuffle/round_rev...）
-> 输出：脱敏xlsx + 字典json + 方案md + 还原md

预览仅显示非 _余项 列，避免泄露余数。

7. 文档脱敏（Word / PPT）

Office Open XML 本质为 ZIP 包，文本存于 word/*.xml / ppt/slides/*.xml 的 <w:t> / <a:t> 节点。

JSZip.loadAsync(buf)
-> collectDocText(): 抽取所有 run 文本（extractRuns）
-> detect(text) 识别敏感项
-> xmlTextReplace(): 在 <w:t>/<a:t> 内部做正则替换（run 级，保格式）
-> 重写 zip 内对应 xml -> generateAsync(blob)

关键：替换发生在 run 内部文本，不破坏样式/排版；多 run 拆分时先聚合段落文本再替换，降低漏替。

8. ZIP 递归处理

recurseZip(zip, log):
  for each entry:
    .zip    -> 递归解包后再打包
    .docx/.pptx -> 识别+run级替换
    .xlsx/.csv -> 识别+单元格替换
    .pdf    -> 遮挡（需 pdf.js）
    .png/.jpg -> 遮挡（需 OCR）

支持嵌套 ZIP：内层 ZIP 先解包处理再重新打包回填。

9. PDF / 图片脱敏（两种模式）

9.1 转为 Word 脱敏（可逆）

  • PDF：pdf.js 逐页抽取文本（并尽力提取 AcroForm 表单字段值），用 autoReplMap 对全部敏感项做令牌化，构造最小 docx（makeDocxFromText）输出 .docx。
  • 图片：tesseract.js OCR 得到文本，同样令牌化后输出 .docx。
  • 因产物是结构化文档，令牌进全局字典，可凭主字典还原。

9.2 遮挡式（不可逆）

  • PDF：pdf.js 抽取文本项与其变换矩阵，估算包围盒，用 PDFLib 在对应位置绘制黑色矩形。
  • 图片：tesseract.js OCR 得到词框，Canvas 填充黑色矩形。
  • 像素/版面被打码后信息永久丢失，不支持还原；保留原格式。

引擎加载策略：ensurePdf / ensureOcr 优先加载 libs/ 本地文件，缺失时回退 CDN（opts 列表），从而实现彻底离线或联网兜底。

10. 还原流程

上传 脱敏文件 + 主字典json (+口令)
-> 构建 token->original 映射（加密类先 decryptVal）
-> 表格：按列元数据路由（token/encrypt/shuffle/round_rev），隐藏列跳过
-> 文档：在 <w:t>/<a:t> 内反查替换
-> 输出《含明文》版本

正则按令牌长度降序拼接，避免 K1-0001 误伤 K1-000012 子串。

11. 安全模型

  • 数据不出本机：无 fetch/上传；所有计算在本地。
  • 口令不落盘：仅用于派生密钥，不写入字典。
  • 盐随字典：加密列 salt 存于字典元数据，口令独掌即可还原。
  • 字典可加密：主字典支持 AES-GCM + PBKDF2 口令加密导出/导入，口令仅本次会话使用、不落盘。
  • 主字典=明文全集：丢失不可逆、泄露即失效，须加密保管、严禁外发。

12. 限制与后续路线

已实现（本期）

  • PDF / 图片「转为 Word 脱敏（可逆）」+「遮挡式（不可逆）」双模式。
  • pdf.js / tesseract.js 及训练数据本地化，彻底离线。
  • 字典 AES-GCM 口令保护导出/导入。
  • 批量文件夹拖拽 + 进度反馈。
  • 扩展格式：.xls（SheetJS）、旧版 .doc 优雅提示、PDF 表单字段纳入提取。

当前限制

  • 识别为启发式，需人工核对；极端复杂 run 拆分可能漏替。
  • 「转为 Word」会丢失原 PDF/图片的版面与格式，仅保留文本与脱敏语义。
  • ZIP 内部的 PDF/图片仍走遮挡式（不可逆）以保证结构一致；如需可逆请单独用单文件模式处理。
  • 旧版二进制 .doc 需先在 Word 另存为 .docx。
