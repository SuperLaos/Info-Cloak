## Обзор

Этот инструмент — **однофайловое, полностью клиентское, работающее без сети** средство маскирования и восстановления данных. Не требуется ни подключение к сети, ни загрузка на сервер: все вычисления выполняются локально в вашем браузере (Chrome / Edge). Он предназначен для маскирования личных данных и коммерчески чувствительной информации перед передачей третьим лицам, партнёрам или в публичные каналы, а также для восстановления в рамках разрешённых полномочий.

## Возможности

- **Поддержка всех форматов**: Excel / CSV / Word / PowerPoint / PDF / изображения / ZIP (включая вложенные) / устаревший `.xls` (через SheetJS) / устаревший `.doc` (предложение сохранить как docx)
- **Маскирование + восстановление (в обе стороны)**:
  - Структурированные документы (таблицы, Word, PPT, документы внутри ZIP) поддерживают обратимое маскирование (токенизация / AES / перемешивание / округление чисел) и согласованное восстановление.
  - **PDF / изображения поддерживают два режима**:
    - «Закрытие (необратимое)» — непосредственно закрашивает пиксели/векторы страницы чёрными блоками, что соответствует физической природе PDF/изображения.
    - «Преобразование в Word с маскированием (обратимое)» — сначала извлекает текст и поля форм локальным PDF-движком / OCR, автоматически токенизирует и создаёт минимальный `.docx`. Токены попадают в глобальный словарь, поэтому **исходный текст можно восстановить по словарю**.
- **13 категорий чувствительных данных**: имя, организация, удостоверение личности, код предприятия, мобильный телефон, городской телефон, банковская карта, электронная почта, сумма, дата, адрес, URL, номер документа.
- **Различные методы**: токенизация / маскирование / хеширование / обобщение / шифрование AES-GCM / случайное перемешивание / округление чисел (обратимое с зашифрованным столбцом остатка) / удаление столбца
- **Глобальный словарь (одно значение — один код)**: один и тот же открытый текст отображается в один и тот же токен во всех файлах и столбцах, обеспечивая согласованность связей и точное восстановление; поддерживается **экспорт с защитой парольной фразой (файл словаря, зашифрованный AES)**.
- **Полная автономность**: PDF-движок (pdf.js) и OCR изображений (tesseract.js + локальный wasm + языковые пакеты китайского/английского) полностью упакованы в `libs/`, с встроенным резервным CDN — **работает даже без сети**.
- **Пакетная обработка**: перетаскивание папок (с рекурсивным обходом) и нескольких файлов, массовое маскирование по стратегии по умолчанию, живой индикатор прогресса и журнал, результаты объединяются в ZIP.

## Поддерживаемые форматы и обратимость

| Формат | Маскирование | Восстановление |
|--------|--------------|----------------|
| CSV / Excel (вкл. .xls) | Да | Да |
| Word / PowerPoint (вкл. поля форм PDF) | Да | Да |
| ZIP (вложенные) | Да | Да (рекурсивно) |
| PDF / изображения · закрытие | Да | Нет (необратимо) |
| PDF / изображения · режим Word | Да | Да (через глобальный словарь) |

> Примечание: режим «преобразование в Word» для PDF/изображений теряет исходную вёрстку (сохраняются только извлечённый текст/поля и токены), но позволяет полностью восстановить исходный текст. Закрытие сохраняет вёрстку и необратимо. Переключение между режимами — через выпадающий список в карточке загрузки документа.

## Быстрый старт

1. Откройте `InfoCloak_V2.html` в Chrome / Edge (двойной щелчок).
2. Выберите функцию в левом меню: ① Маскирование таблиц ② Маскирование документов ③ Восстановление ④ Глобальный словарь.
3. Загрузите файл → выберите метод (для PDF/изображений переключите «Закрытие / Word» в карточке документа) → создайте → скачайте результат.
4. **Пакетная обработка**: перетащите всю папку в область «Пакетная обработка» или выберите папку. После запуска маскирование выполняется по стратегии по умолчанию, результаты объединяются в ZIP, прогресс отображается в реальном времени.
5. Для восстановления перейдите в ③ Восстановление, загрузите маскированный файл + главный словарь (зашифрованные словари требуют сначала ввести парольную фразу).

## Глобальный словарь и защита парольной фразой

- Глобальный словарь обеспечивает «одно значение — один код» во всех файлах/столбцах и является единственной основой для восстановления.
- При экспорте можно задать **парольную фразу**: словарь шифруется в AES-GCM (вывод ключа PBKDF2, 150000 итераций) и сохраняется как пакет `.json` с полями `salt`/`iv`/`ct`.
- Для импорта зашифрованного словаря требуется правильная парольная фраза; она никогда не записывается в файл словаря и используется только для вывода ключа текущей сессии.
- **Главный словарь содержит все соответствия открытого текста и является наиболее чувствительным активом — храните его локально и никогда не передавайте вместе с маскированными файлами.**

## Обратимость методов маскирования

| Метод | Обратим | Требуется для восстановления |
|-------|---------|------------------------------|
| Токенизация | Да | Главный словарь |
| Шифрование AES | Да | Главный словарь + парольная фраза |
| Случайное перемешивание | Да | Главный словарь (отображение по значениям) |
| Обратимое округление чисел | Да | Главный словарь + парольная фраза |
| Маскирование / Хеширование / Обобщение / Удаление / Закрытие | Нет | — |

## ⚠️ Правила загрузки словаря (обязательно к прочтению)

**Словарь НЕ сохраняется автоматически!** После маскирования он существует только в памяти браузера и теряется при закрытии страницы. Его необходимо вручную скачать в разделе ④ Глобальный словарь.

| Метод, использованный при маскировании | Что скачать в ④ |
|---|---|
| Только токенизация / перемешивание | **Скачать `主字典.json` (главный словарь)** (открытый текст) |
| Шифрование AES / обратимое округление | **Скачать `加密主字典.json` (зашифрованный главный словарь)** + задать парольную фразу |
| Маскирование / Хеширование / Обобщение / Удаление | Не требуется (необратимо, восстановление невозможно) |

**Соответствие при восстановлении**: скачан `主字典.json` → загрузите его, парольную фразу оставьте пустой; скачан `主字典_加密.json` → загрузите его и введите парольную фразу, заданную ранее.

## Конфиденциальность и безопасность

- Данные никогда не покидают ваше устройство; сетевая загрузка отсутствует (после локализации `libs/` инструмент работает полностью офлайн).
- Парольная фраза используется только для вывода ключа текущей сессии и не записывается в файл словаря.
- **Главный словарь содержит все соответствия открытого текста и является наиболее чувствительным активом — храните его локально и никогда не передавайте вместе с маскированными файлами.**
- Инструмент предоставляется для систематизации информации и обучения; он не гарантирует полной безопасности данных. Сделайте резервную копию исходных файлов.

## Известные ограничения

- Режим «преобразование в Word» для PDF/изображений зависит от извлечения текста; качество маскирования отсканированных документов зависит от точности OCR. Сложная вёрстка упрощается до обычного текста.
- Устаревший формат `.doc` не разбирается напрямую — сначала сохраните его как `.docx` в Word/WPS.
- Закрытие PDF/изображений необратимо; перед использованием убедитесь, что восстановление не требуется.
